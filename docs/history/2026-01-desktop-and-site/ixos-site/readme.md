# Ixos website

Next.js site/landing variants in the monorepo. From the root: `npm ci`, `npm run site:dev`; production check: `npm run build --workspace ixos-site` (Webpack). Read local `AGENTS.md` for shared demo and visual constraints.

All product features are free; there is no billing or account unlock. Shared scripted desktop demos use `@ixos/ixos-ui` through `src/landing/DemoSurface.tsx` and `DemoSurfaceShell.tsx`. Scripted results/animation timings are demonstrations, not benchmark observations. Archived planning docs preserve earlier designs under `docs/archive/pre-restoration/ixos-site/`.

Current engine evidence lives in root `reports/restoration/GATE3.md`. Earlier site numerical snapshots are historical/illustrative and do not describe the new CLI. Site polish and broader claim/copy review remain the owner's workstream; native desktop/platform checks are separate from a site build.
