# Brandable Model Names

Each name below maps to a concrete artifact and is stable across releases.

## Ixos Flash (`ixos-flash-v2`)
Positioning: the production-default Flash tier.

## Ixos Pro (`ixos-pro-v2`)
Positioning: the Pro retrieval tier (fusion/cascade).

## `potion-base-8m-int8` (internal)
Positioning: internal dependency used by Ixos Pro, not a user-facing mode.

## Flash Core (`ixos-flash-v1`)
Positioning: legacy baseline kept for regression comparisons.
