# Inspiration Matrix

## lando
- **Hero Strategy:** Strong focus on CLI tools integrated seamlessly into the layout. Minimalist typography and bold geometric framing.
- **Layout Rhythm:** Heavy contrast between tight terminal-like layouts and expansive full-width content blocks. Staggered vertical scroll reveals.
- **Section Transitions:** Sharp, snapping transitions between dark mode and stark white.
- **Texture Language:** Monospace meta-text over sleek gradients, terminal window chrome used as structural blocks.
- **Motion Pacing:** Fast, snappy, instantaneous micro-interactions.
- **Typography:** Large display fonts for headlines, tight mono space for the technical details.
- **Ixos Translation:** Adopt the stark, confident contrast without overusing the terminal aesthetic. Use mono purely for labels, keeping the core Ixos search interface premium and clean.

## convex
- **Hero Strategy:** "It just works" vibe. A central, functional visualization showing data flow or sync, with strong glowing accents.
- **Layout Rhythm:** Very balanced, two-column grids turning into full-width "how it works" panels. Symmetrical.
- **Section Transitions:** Smooth fades, overlapping cards that stick as you scroll.
- **Texture Language:** Soft glowing blurs (teal/purple vibes), frosted glass cards.
- **Motion Pacing:** Fluid, continuous, breathing motion that feels "live."
- **Typography:** Friendly, highly legible sans-serif.
- **Ixos Translation:** Integrate the sticky, overlapping card strategy for the deeper dives. We can use the soft amber glow here instead of standard blue, maintaining the "live" sync feeling for our semantic indexing.

## graphite
- **Hero Strategy:** Engineering-first confidence. High-density information that looks beautiful. Command palettes and graph visualizations taking center stage.
- **Layout Rhythm:** Dense, multi-column dashboard aesthetics woven into landing page storytelling.
- **Section Transitions:** Line-drawing reveals and grid-based expanding panels.
- **Texture Language:** Wireframes, dots, grid lines, sharp borders.
- **Motion Pacing:** Deliberate, exact, technical typing and unfolding.
- **Typography:** Very structured, tabular data styles mixed with strong sans-serif headers.
- **Ixos Translation:** Perfect inspiration for our Desktop UI integration. We need the "high density" feel for power users (showing score breakdown and snippets) without losing clarity.

## vercel
- **Hero Strategy:** The gold standard of developer marketing. Iconic glowing triangle, absolute minimalism.
- **Layout Rhythm:** Bountiful white/dark space, centering massive, singular statements followed by crisp product grids.
- **Section Transitions:** Subtle scroll-driven fading of large text, elegant border highlights as elements enter viewport.
- **Texture Language:** Absolute lack of noise. Perfection in border radii, 1px lines, and subtle drop shadows.
- **Motion Pacing:** Ethereal, sophisticated, smooth.
- **Typography:** Inter/Geist. Perfect kerning, perfect hierarchy.
- **Ixos Translation:** The masterclass in restraint. Ixos must avoid messy SVG blobs and adopt this 1px precision and spatial discipline, especially in how we present the "Pipeline" and "Proof" sections.

## site 4 (baseline)
- **Hero Strategy:** Current state. Too chaotic or too generic. Leans into "AI kits" and floating abstract shapes that don't mean anything.
- **Layout Rhythm:** Horizontal scrolling issues, fragmented sections.
- **Section Transitions:** Abrupt or confusing sideway scrolls that break the mouse wheel flow.
- **Texture Language:** Overused glowing orbs that lack connection to the product.
- **Motion Pacing:** Distracting, not tied to narrative.
- **Typography:** Unbalanced hierarchy, sometimes too large on mobile.
- **Ixos Translation:** We are ripping this out. The baseline proves we need a unified structural language (vertical only) and a distinct thematic direction rather than just "AI shapes."

## Anti-Patterns Identified
1. **The "AI Kit" aesthetic:** Generic glowing SVG blobs that don't explain the product.
2. **Repeated Demo Syndrome:** Showing the exact same search bar mockup in every section just to take up space.
3. **Sideways Scroll Hijacking:** Taking away vertical scroll control for a horizontal section—breaks user trust and flow.
4. **Empty Space Void:** Using massive padding to compensate for a lack of content or story in a section.
5. **Form over Function in Diagrams:** Diagrams that are just lines and circles instead of using actual UI primitives (chips, tags, search snippets).
