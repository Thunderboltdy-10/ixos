2://!
3://! This module provides tamper-resistant ranking that defends against:
4://!

6://! - **File manipulation**: Creating keyword-stuffed content
7://! - **Bot patterns**: Automated queries designed to influence rankings
8://!
9://! ## Composite Scoring
10://!
11://! The final score is a weighted combination:
12://!
13://! ```text
14://! final_score =
15://!     semantic_score * 0.4 +    // From hybrid engine
16://!     integrity_score * 0.3 +   // Penalizes suspiciously recent modifications
17://!     temporal_score * 0.1 +    // Favors older, stable files
18://!     behavior_score * 0.2      // Penalizes bot-like access
19://! ```

## src/ixos_rank\mod.rs
1://! Ranking and search engines for Ixos
2://!
3://! This module provides hybrid search capabilities combining:
4://!
5://! - **Lexical search**: Fast keyword-based matching
6://! - **Semantic search**: Embedding-based similarity
7://! - **Adaptive hybrid**: Attack-resistant combination of both
8://!
9://! ## Architecture
10://!
11://! ```text
12://! Query
13://!   ¦
14://!   ?
15://! +--------------------------+
16://! ¦   AdaptiveHybridEngine   ¦
17://! +--------------------------+
18://!              ¦
19://!   +---------------------+
20://!   ¦                     ¦
21://!   ?                     ?
22://! +----------+      +-----------+
23://! ¦ Lexical  ¦      ¦ Semantic  ¦
24://! ¦ Engine   ¦ --?  ¦ Engine    ¦
25://! +----------+      +-----------+
26://!   Phase 1           Phase 2
27://!   (Fast)          (Accurate)
28://! ```
29://!
30://! ## Attack Detection
31://!
32://! The hybrid engine monitors lexical search quality to detect degradation attacks:
33://!
34://! - **High result count**: Many files matching query terms
35://! - **Low match quality**: Few exact matches, many partial matches
36://!
37://! When an attack is detected, the engine falls back to alternative strategies
38://! that don't rely on lexical pre-filtering.
39://!
40://! ## Example
41://!
42://! ```rust,no_run
43://! use ixos_protocol::ixos_rank::{
44://!     AdaptiveHybridEngine, StubLexicalEngine, StubSemanticEngine,
45://! };

49://!     let lexical = StubLexicalEngine::new();
50://!     let semantic = StubSemanticEngine::with_stub_model();

52://!
